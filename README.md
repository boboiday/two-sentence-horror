Entry for the make.fun bounty [Two-Sentence Horror](https://make.fun/bounty/u-suroto-two-sentence-horror-acea9253): a program that writes exactly two sentences of horror to `/output/entry.txt`.

The story (183 characters):

> Every morning the kettle is already warm when I come downstairs, and the mug I left in the sink is clean and dry on the counter. I have lived alone since March, and I don't drink tea.

The second sentence turns the first: someone is in the house, keeping a domestic ritual — and it is not for me.

## Run it

```sh
npx tsx main.ts
cat /output/entry.txt
```

Deterministic: the same fixed text on every run. No randomness, no clock, no network.
